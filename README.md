# budget-pacer（月度预算发言频率调节）

设定一个月度 API 预算，让麦麦的整月花费**贴近预算**——既不超支，也不因过度保守而浪费额度。

不是「超支就惩罚」的事后阶梯，而是**预算节奏闭环**：花快了就压低发言频率，花慢了就放松，让累计花费曲线整月贴着预算斜率走。

## 工作原理

```
LLM 调用 → llm_usage 明细表（每次请求实时写入 cost）
   ↓ 宿主每 15 分钟增量聚合
statistics_model_hourly（小时桶，含 cost）
   ↓ 插件每 N 秒读取
model_trend(days=32, bucket="hour", top_models=50, metric="cost")
   ↓ 按「本月 1 日 0 点」裁剪求和 → 本月累计花费 S
compute_adjust(S, B, now) → 目标倍率
   ↓ frequency.set_adjust(chat_id, 倍率)
该会话的发言频率被缩放
```

### 控制律

```
p  = 月度时间进度（月初用 p_floor_days 兜底，避免噪声放大）
q  = 本月花费 / 月预算
pacing = q / p            # >1 表示花费超前于时间进度

pacing 在死区内        → 不动作，保持 1.0
pacing > 1            → target = 1 / pacing（压低）
pacing < 1 且允许加频  → target = 1 / pacing（放松）
已花满预算            → 走硬闸门（over_budget_adjust）
```

**为什么用闭环反馈而不是开环预测**：每条消息成本不可预测（回复长度、记忆召回、工具调用都影响 token），且降频与降花费并非 1:1（记忆检索等模块的花费不随发言频率线性下降）。但只要「降频 → 花费下降」这个方向成立，闭环就会自行收敛，**不需要知道增益是多少**。

### 一个自愈特性

月末超支降到 0.1 倍率后，花费近乎停滞，时间继续走，`pacing` 会自动回落；到下月 1 日倍率自动复位为 1.0。除了跨月重置，不需要任何人工干预。

## 示例

预算 30 元：

| 时间 | 时间进度 | 已花 | 花费进度 | pacing | 倍率 |
|---|---|---|---|---|---|
| 第 5 天 | 16.7% | 5.0 | 16.7% | 1.00 | 1.00 |
| 第 5 天 | 16.7% | 7.5 | 25.0% | 1.50 | 0.67 |
| 第 10 天 | 33.3% | 5.0 | 16.7% | 0.50 | 1.00 |
| 第 20 天 | 66.7% | 26.0 | 86.7% | 1.30 | 0.77 |
| 第 25 天 | 83.3% | 30.5 | 101.7% | 1.22 | 0.10（闸门） |
| 第 29 天 | 96.7% | 30.0 | 100.0% | 1.03 | 1.00 |

## 安装

把整个 `budget-pacer` 目录放进 MaiBot 的 `plugins/` 目录，确认 `_manifest.json` 与 `plugin.py` 同级，**完整重启 MaiBot**（capabilities 变更后必须重启，热重载不生效）。

⚠️ 首次启动不会立刻调节：默认配置下 `monthly_limit = 30.0`、`enabled = true`。若不希望默认就生效，先把 `[plugin] enabled = false`，配置好预算后再开启。

## 配置（`config.toml`，Runner 首次加载自动生成）

```toml
[plugin]
config_version = "1"
enabled = true

[budget]
monthly_limit = 30.0              # 月度预算（元）；<=0 表示不调节
check_interval_seconds = 300      # 巡检间隔（秒），建议 >= 300
apply_private = true              # 是否同时调节私聊
p_floor_days = 1.0                # 月初进度下限（折算天数），防噪声
deadband = 0.10                   # 死区带宽，节奏比在此范围内不调整
smoothing = 0.35                  # 指数平滑系数 0~1
min_adjust = 0.10                 # 最低倍率；设 0 表示允许完全静音
max_adjust = 1.00                 # 最高倍率；>1 才可能加频
allow_boost = false               # 花费滞后时是否提高倍率以贴近预算
over_budget_adjust = 0.10         # 达到预算后的闸门倍率
override_scan_limit = 2000        # 例外会话花费明细的扫描条数上限

[permission]
admin_ids = []                    # 管理员 QQ 号；留空则所有人可操作

# 单群例外额度（可选）。与全局闸门「取更严者」：
# 总账超了大家都省，某群自己超了它额外再省。
[[overrides]]
group_id = "123456789"
monthly_limit = 5.0
enabled = true
```

`overrides` 写法宽容：标准数组表、单个字典、或字符串 `"123456:5.0，789012:3.0"` 均可。
`admin_ids` 同样宽容：`["123"]`、`"123"`、`"123,456"`、整数 `123`、以及 `"qq:123"` 前缀写法都可识别。

## 命令

| 命令 | 说明 |
|---|---|
| `/预算` | 查看预算、已花、时间进度、节奏比与当前倍率 |
| `/预算 30`、`/预算 设置 30` | 临时修改本月预算（不写配置文件） |
| `/预算 暂停` | 暂停调节，并把倍率立即复位为 1.0 |
| `/预算 恢复` | 恢复调节并立即重新判定 |
| `/预算 重置` | 清除临时预算、复位倍率、清空会话缓存 |

LLM 也可以调用 `budget_status` 工具回答「这个月花了多少」「为什么最近话少」这类问题。

## 权限

- `admin_ids` 留空 → **所有人**可操作（fail-open）。
- 配置后 → 仅列表内 QQ 号可操作。
- 非管理员被拒时**完全静默**：不发送任何消息，只写日志。

## 调参指南

| 参数 | 调大 | 调小 |
|---|---|---|
| `deadband` | 更稳但迟钝 | 更灵敏但爱动 |
| `smoothing` | 响应快、易过冲 | 平滑、收敛慢 |
| `p_floor_days` | 月初更保守 | 月初更激进 |
| `min_adjust` | 保留更多存在感 | 允许更安静 |
| `allow_boost` | 开启后追求「贴着预算花」，bot 会更活跃 | 关闭则语义退化为「不超支」 |

建议先用默认值观察一周，再决定是否提高 `max_adjust` 并打开 `allow_boost`。日志会打印每次调节的完整依据。

## 与 expenses-summary 的关系

两者**松耦合、互不调用**：

- `expenses-summary`：日粒度、只读、面向群友（「今天花了多少」）
- `budget-pacer`：月粒度、有副作用、面向管理员（「为什么 bot 变安静了」）

取数算法（时间标签解析、窗口内求和、序列提取）与前者同源，但按「月窗口」泛化。

## 故障排查

- **命令没反应**：确认 WebUI「Bot 配置 → 命令」里组件已注册；capabilities 改动后必须完整重启。
- **倍率没生效**：宿主侧倍率是**内存态**，重启即失效。插件会在 `on_load` 后从状态文件恢复并重新下发；若状态文件被删除，需要等一轮巡检（默认最多 5 分钟）。
- **新建的群没被调节**：由 `chat.receive.after_process` hook（observe 模式）兜底补设，需该群产生第一条消息。

  ⚠️ 这里**不能**改用 `@EventHandler(event_type=EventType.ON_MESSAGE)`：该事件的派发在 MaiBot 1.2.5 中被注释掉了（`src/chat/message_receive/bot.py:846`），注册了也永远不会触发——一个「静态检查全绿、真机静默失效」的坑。
- **花费明显偏低**：若活跃模型超过 50 个，`top_models` 会被宿主截断（硬上限 50）。日志中「本月花费前三位」可辅助核对。
- **例外群额度不准**：宿主的过滤器只支持等值匹配，无法按时间范围查询，因此按 `id` 倒序扫描最近 `override_scan_limit` 条明细后自行裁剪。触及上限时日志会告警。
- **重启后重复压制**：检查日志是否出现「跨月重置」——跨月会自动复位倍率与临时预算。

## 兼容性

- MaiBot ≥ 1.0.9，SDK ≥ 2.6.0
- 声明能力：`send.text` / `statistics.local.model_trend` / `frequency.set_adjust` / `chat.get_all_streams` / `database.query`
- 币种：宿主 `cost` 字段单位为**元**，取自 `config/model_config.toml` 中的单价配置
